# 🔥 Habit Tracker

A clean and modern web-based Habit Tracker that helps you build better habits and stay consistent.

## ✨ Features
- Add, edit & delete habits
- Daily check-in with streak tracking
- Visual progress (streaks, completion rate)
- Responsive design (works on mobile & desktop)
- Local storage support (data stays even after refresh)
- Simple and beautiful UI

## 🛠️ Tech Stack
- JavaScript
- TypeScript
- Python

## 🚀 How to Use
1. Clone the repository
2. intall npm
3. run npm dev
4. Start tracking your habits!
